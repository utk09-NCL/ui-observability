# Security Policy

## Report a Vulnerability

Report a security vulnerability in private. Use GitHub private vulnerability reporting.

1. Open the **Security** tab of the [repository](https://github.com/utk09-NCL/ui-observability).
2. Select **Report a vulnerability**.
3. Give the affected version, the steps to reproduce the problem and its effect.

Do not open a public issue for a vulnerability. A public issue shows its content to each reader.

## Supported Versions

The latest 1.x release gets security fixes. An earlier release does not get security fixes.

## Scope

The [threat model](docs/threat-model.md) gives the trust boundaries, the controls and the items that are out of scope.

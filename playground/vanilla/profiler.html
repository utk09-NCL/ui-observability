profiler overhead benchmark

This page measures the cost of one begin() and end() pair of a probe. Each number is a measurement of this browser and this machine. The page makes no claim about another machine.

Keep this tab visible during the run. Close other tabs and each program that uses the CPU. No capture runs on this page.

Back to the playground

Modes

  • baseline. A plain loop with a counter. The page does not subtract it from another mode.
  • off. Pairs on a probe while the profiler is off.
  • on. Pairs on a probe with sampleEvery: 1.
  • sampled. Pairs on a probe with sampleEvery: 64.

Result in nanoseconds per pair

The page shows no average. With 101 runs, p99 is the second highest run. A p99.9 value needs 1000 runs or more. The mark low resolution means that the p50 run lasts fewer than 100 clock ticks. The clock step then limits the value. Use more pairs per run.

Environment

JSON



    

      URL parameters. autorun=1 starts the run at load. runs= and
      pairs= set the inputs. A value must be a whole number from 1 to 10000 for runs
      and from 1 to 50000000 for pairs. Another value uses the default.
    

    

      report=<url> sends the JSON with a POST request when the run ends. The JSON
      holds the user agent text, crossOriginIsolated, the clock tick and the timings.
      The page accepts only the page host, localhost, 127.0.0.1 and [::1], with http or https.
    

    

      The title of the page shows the state. It is running during a run,
      done after a run and failed after a fault.
